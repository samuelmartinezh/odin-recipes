# Odin Recipes
Odin Recipes is a basic recipe website. The site consists of a main page with links to a few recipes.

## Outcome
- I learned to build the initial basic structure of a project.
- I learned to build the initial structure of a webpage.
- I learned the difference between elements and tags.
- I learned to use basic HTML elements such as headings, paragraphs, and lists.
- I learned about element attributes.
- I learned to navigate from my page to other sites on the internet.
- I learned to navigate between pages on my site.
- I learned to insert images.
- I learned about different image formats.
- I learned basic Git commands such as cd, mv, cp, rm, mkdir, ls, touch, git status, git add, git log, git commit, git clone, and git push.
- I learned the difference between Git and GitHub and how to use them together.
- I committed to writing good commit messages.
